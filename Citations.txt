
===============================================================================
CITATION & REFERENCE MANIFEST FOR 3D RECONSTRUCTION PIPELINE
================================================================================

This document compiles the formal academic citations, foundational papers, official software 
references, repositories, and documentation links for all components, frameworks, 
compilers, and dependencies utilized in Backend.py, strictly ordered from highest to lowest project impact.

--------------------------------------------------------------------------------
TIER 1: CORE WORKFLOW & RECONSTRUCTION PIPELINE DRIVERS
--------------------------------------------------------------------------------

1. COLMAP
   Role: Camera pose estimation, sparse point cloud generation, feature matching.
   Official Website: https://colmap.github.io/
   GitHub Repository: https://github.com/colmap/colmap
   Academic Citations:
     * Schönberger, J. L., & Frahm, J.-M. (2016). Structure-from-Motion Revisited.
       In IEEE Conference on Computer Vision and Pattern Recognition (CVPR), pp. 4104–4113.
       DOI / Link: https://doi.org/10.1109/CVPR.2016.445
       Paper: https://demuc.de/papers/schoenberger2016sfm.pdf
     * Schönberger, J. L., Zheng, E., Pollefeys, M., & Frahm, J.-M. (2016). Pixelwise 
       View Selection for Unstructured Multi-View Stereo.
       In European Conference on Computer Vision (ECCV), pp. 501–518.
       DOI / Link: https://doi.org/10.1007/978-3-319-46487-9_31
       Paper: https://demuc.de/papers/schoenberger2016mvs.pdf

2. NERFSTUDIO & SPLATFACTO
   Role: Main neural training pipeline, 3D Gaussian optimization, and PLY exporter.
   Official Website: https://docs.nerf.studio/
   GitHub Repository: https://github.com/nerfstudio-project/nerfstudio
   Academic Citation:
     * Tancik, M., Weber, E., Ng, E., Li, R., Iyer, P., Kerr, J., Terrando, D., 
       Kulhanek, J., Chen, A., Gao, C., Wang, J., Austin, D., Luo, R., Tulsiani, S., 
       & Kanazawa, A. (2023). Nerfstudio: A Modular Framework for Neural Radiance 
       Field Development.
       In ACM SIGGRAPH 2023 Conference Proceedings (SIGGRAPH '23), Article 72.
       DOI / Link: https://doi.org/10.1145/3588432.3591516
       Documentation: https://docs.nerf.studio/

3. FFMPEG
   Role: Video extraction pipeline, converting raw input footage to frame sequences.
   Official Website: https://ffmpeg.org/
   GitHub / Git Repository: https://git.ffmpeg.org/ffmpeg.git
   Documentation: https://ffmpeg.org/documentation.html
   Citations & References:
     * FFmpeg Developers. (2000–present). FFmpeg: A complete, cross-platform solution 
       to record, convert and stream audio and video.
       Website: https://ffmpeg.org
     * Tomar, S. (2006). Converting Video Formats with FFmpeg.
       Linux Journal, 2006(146), Article 10.
       Link: https://www.linuxjournal.com/article/8988

TIER 2: 3D GAUSSIAN SPLATTING & MESH GENERATION ENGINES
--------------------------------------------------------------------------------

4. GSPLAT & 3D GAUSSIAN SPLATTING
   Role: Fast rasterization and CUDA projection engine driving splatfacto.
   Official Website / Docs: https://docs.gsplat.studio/
   GitHub Repository: https://github.com/nerfstudio-project/gsplat
   Original 3DGS Project: https://repo-sam.inria.fr/fungraph/3d-gaussian-splatting/
   Academic Citations:
     * Kerbl, B., Kopanas, G., Leimkühler, T., & Drettakis, G. (2023). 3D Gaussian 
       Splatting for Real-Time Radiance Field Rendering.
       ACM Transactions on Graphics (TOG), 42(4), Article 139, pp. 1–14.
       DOI / Link: https://doi.org/10.1145/3592433
       Paper: https://repo-sam.inria.fr/fungraph/3d-gaussian-splatting/3d_gaussian_splatting_low.pdf
     * Ye, V., & Tancik, M. (2023). gsplat: An Open-Source Library for Gaussian Splatting.
       Repository: https://github.com/nerfstudio-project/gsplat

5. OPEN3D
   Role: Point cloud processing, normal estimation, KDTree queries, and Poisson mesh reconstruction.
   Official Website: http://www.open3d.org/
   GitHub Repository: https://github.com/isl-org/Open3D
   Academic Citations:
     * Zhou, Q.-Y., Park, J., & Koltun, V. (2018). Open3D: A Modern Library for 3D 
       Data Processing.
       arXiv preprint arXiv:1801.09847.
       DOI / Link: https://doi.org/10.48550/arXiv.1801.09847
     * Kazhdan, M., & Hoppe, H. (2013). Screened Poisson Surface Reconstruction.
       ACM Transactions on Graphics (TOG), 32(3), Article 29, pp. 1–13.
       (Underlying method used for triangle mesh generation)
       DOI / Link: https://doi.org/10.1145/2487228.2487237
       Paper: https://hhoppe.com/poissonrecon.pdf
