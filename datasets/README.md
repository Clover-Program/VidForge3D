# Datasets & Credits

The sample dataset in this directory is sourced from [nerfstudio's gsplat](https://github.com/nerfstudio-project/gsplat). 

It is provided here purely for convenience and out-of-the-box functionality so users do not have to pull the entire upstream repository manually. If you already have `nerfstudio` or `gsplat` installed locally, this copy is not strictly necessary.
